# GroundSense AI — 5-minute launch checklist

## Before deploying

- Use the full v2.0 project folder, not only `public/`.
- Keep the existing Netlify environment secret `OPEN_AI_KEY`; v2 also accepts `OPENAI_API_KEY`.
- Deploy from the GitHub repo linked to the existing Netlify site.

## After Netlify publishes

1. Open `/facilitator.html`.
2. Create a fresh rehearsal session and PIN.
3. Confirm the facilitator badge says **AI key configured**.
4. On a second device, join Table 1 from the participant page.
5. In Ground Mode, enter station code `3814` and confirm the Older resident signal appears.
6. Save a short working hypothesis.
7. Advance to AI Mode and tap **Synthesise the evidence**. Confirm the output badge says **Live AI**. If it says **Prepared backup**, check the function logs/API key before the live run.
8. Advance to Human Context, submit a final decision, then advance to Debrief.
9. Back on the facilitator screen, confirm Table 1 shows Ground / Hypothesis / AI / Decision status.
10. Tap **Reset table data** and confirm the participant screen returns to a clean Ground round.

## Room setup

- Print `/print.html`.
- For 80–100 pax, use two copies of each of the eight Ground Stations.
- Keep the Final Ground Update covered until Round 3.
- Use one shared device per table.
- Tell participants explicitly: **one runner leaves the table at a time; swap runners each trip**.

## Live timing

- Ground: 3 min
- AI: 3 min
- Human Context: 2 min
- Debrief: 2–4 min
